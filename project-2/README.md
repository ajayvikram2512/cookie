# Project 2 - Mini Store

Simple React + Tailwind CSS project for the Cookie Inc. Project 2 task.

## Concepts covered

- React
- Tailwind CSS
- Component composition
- Props
- useState
- React Router
- Link
- Dynamic route: `/product/:id`
- Basic form handling
- Responsive Tailwind grid

## Run the project

```bash
npm install
npm run dev
```

Then open the localhost URL shown by Vite.

## Build

```bash
npm run build
```
