# Project 3 - Product Dashboard

Simple React project covering the required Project 3 concepts.

## Included

- useEffect
- Custom hook
- Context API
- Axios API integration
- Reusable UI button component
- React Router
- Protected routes
- useNavigate
- Dynamic route `/product/:id`
- Route-based data fetching
- Basic form validation
- Tailwind CSS

## Run

```bash
npm install
npm run dev
```

Open the localhost URL shown by Vite.

## Flow

1. Open the app.
2. You are redirected to Login.
3. Enter your name.
4. Login takes you to the product dashboard.
5. Click View Product to open `/product/:id`.
